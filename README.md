Aplikasi dijalankan dengan :
php artisan serve

Alamat utama aplikasi:
http://127.0.0.1:8000

Asset CSS dan JavaScript telah dikompilasi menggunakan:
npm run build

Dengan demikian, aplikasi dapat digunakan melalui satu alamat utama tanpa perlu membuka port Vite secara terpisah.

Cara Mengakses Aplikasi:
Jalankan MySQL melalui XAMPP.

Buka terminal pada folder proyek.
Jalankan aplikasi:
php artisan serve

Buka alamat:
http://127.0.0.1:8000

Jika belum mempunyai akun, lakukan Register.
Jika sudah mempunyai akun, klik Already registered? untuk masuk ke halaman Login.
Setelah login berhasil, pengguna diarahkan ke Dashboard.
Gunakan navbar untuk mengakses Data Buku, Data Anggota, dan Peminjaman.
Untuk menambah anggota, buka menu Data Anggota lalu pilih Tambah Anggota.
Untuk menghapus anggota, klik tombol Hapus pada daftar anggota.
Untuk keluar dari aplikasi, klik tombol Keluar/Logout.
